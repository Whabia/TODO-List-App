# 📝 To-Do List App

A modern and responsive To-Do List application built using **HTML, CSS, and JavaScript**. This project helps users organize their daily tasks with a clean and user-friendly interface.

## 🚀 Live Demo

## 🚀 Live Demo

[Click here to view the project](https://whabia.github.io/TODO-List-App/)

## ✨ Features

- ✅ Add new tasks
- ✏️ Edit existing tasks
- ✔️ Mark tasks as completed
- 🗑️ Delete tasks
- 💾 Save tasks using Local Storage
- 📱 Responsive design
- 🎨 Clean and modern user interface

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API

## ⚙️ Getting Started

1. Clone the repository

```bash
git clone https://github.com/Whabia/TODO-List-App.git
```

2. Open the project folder.

3. Run `index.html` in your browser.
